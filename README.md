# Piano Tracker

A mobile-first progressive web app for keeping track of piano songs you want to learn and songs you've already learned.

**Live:** [your-vercel-link.vercel.app](https://your-vercel-link.vercel.app)

![Screenshot](screenshot.png)

## Features
- Sign up and log in with Supabase Auth
- Each user's song list is stored in a Supabase (Postgres) database
- Mark songs as "to learn" or "learned"
- Installable on your phone and works offline (service worker + web app manifest)

## Built with
- HTML, CSS, JavaScript
- Supabase (authentication + Postgres database)
- Vercel (hosting)
